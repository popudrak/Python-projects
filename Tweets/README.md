# US Presidential candidates tweets - text mining.

The project sought to determine the type of rhetoric used by presidential candidates in the U.S. based of tweets collected from Twitter api before 2021 elections.

# Project journey

| Model Name |
|------------|
| 1. Preprocessing
| 2. Tokenization
| 3. Stemantization, lemantization
| 4. Finding bigrames and trigrams
| 5. Document Term Matrix (words frequency)
| 6. Hierarchical, agglomerative grouping
| 7. Creating charts, and infographics
